# Бюро переселения привидений

Веб-приложение для оператора бюро, которое переселяет привидений из старых
домов в новые места обитания. Тема сказочная, задача практическая: подобрать
каждому привидению подходящее место, объяснить решение и honestly показать,
если переселение невозможно.

Тестовое задание для вакансии AI-first Developer (MOX). Тема специально
неприменима к реальной жизни — проверяется не предметная область, а умение
довести маленький продукт до рабочего состояния с помощью AI-инструментов.

## Стек

- React + Vite + TypeScript
- Tailwind CSS
- Vitest (юнит-тесты)
- Без бэкенда — всё состояние живёт в памяти браузера

## Как запустить локально

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173` — открой его в браузере.

## Тесты

## Демо-данные

В шапке приложения есть переключатель **демо-данные**: обычные данные / пустой
список заявок / битые данные — так можно быстро посмотреть, как приложение
ведёт себя в каждом из этих состояний, не редактируя код.

## Игровой день

Дедлайны заявок привязаны не к реальным датам, а к номеру игрового дня.
Кнопка **«Следующий день →»** в шапке продвигает время на один день вперёд —
так можно быстро увидеть, как заявка становится просроченной, без ожидания.

## Что проверено вручную перед сдачей

- [x] Пустой список заявок — показывает понятный текст, не белый экран
- [x] Заявка без подходящего места — статус «без места» с явно видимой причиной
      прямо в списке (например «нет свободных мест», «дедлайн просрочен»)
- [x] Место переполнено — статус «переполнено», счётчик занятости растёт при
      ручном добавлении новых заявок в то же место
- [x] Ручной выбор места, конфликтующего с условиями заявки — жёлтое
      предупреждение с причиной конфликта, назначение при этом не блокируется
      (осознанное решение: предупреждение, а не жёсткий запрет)
- [x] Битые/невалидные исходные данные — экран с читаемым списком найденных
      ошибок валидации вместо падения в белый экран
- [x] Смена игрового дня — дедлайны заявок пересчитываются корректно
- [x] Снятие размещения с заявки — статус пересчитывается заново (pending
      или unplaceable, в зависимости от актуальной занятости мест)
